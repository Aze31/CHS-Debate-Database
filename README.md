This react-based site uses the API at https://github.com/gmitch215/TabroomAPI (credit to gmitch215) and basically just gives it a frontend. It will also hopefully include access to most of tabroom's services.
Additionally, there is a feature under development for efficiently dropping cases (using temporary generated access codes) in multiple formats. 

If you would like to try using this app right now, I recommend cloning the repo and running 
npm run dev locally.

Here is my round vision:
## Current State
Currently, this is only a work in progress, and doesn't have its own domain. That will change once the site meets its basic functionality goals.

If you have any suggestions, comments, or advice, open up an issue.

I am currently in the process of making a secure authentication method for handling user data and accessing the NSDA database for relevant information. This would require some time and communication, but eventually this app will be able to access member data and perhaps other tabroom features if approved.

## Functionality goals
The goals of this site include, in descending order of priority:
 - Display member stats (win rate, history, points, degrees)
 - Include a simple interface for member ranking
 - Display school rankings
 - Built in speech drop feature (include more file formats)
 - Future tournament list
 - Track and display tournament results on request

 Reach functionality - needs approval
 - Potentially provide tournament sign up services?
